Olaylar
Bu konseptin trade-off'u:
• + Session sistemiyle birebir aynı — sıfır yeni mental model.
• + İzole PT'yi kullanıcı da görebiliyor, "ne yapıyor?" sorusu cevaplanıyor.
• + Session kapatma/rename/switcher/geri dönüş bedava.
• − Her yeni görev = yeni session → liste şişer, "bu session'da devam et" kavramı geri gelir.
• − Kullanıcının terminali ile agent'ın terminali arasında geçiş = segment değiştirmek, panel hissi yok.
